# PM Progress Update

> **本技能属于 Cindy 插件 `ai-pm-intake`（展示名 TooManyTasks）：动手前先看工具列表，没有名字含 `ghost_call` 的工具就说明不在 Cindy 中，本技能不可用。** 此时不要执行任何步骤，也不要用 shell 或别的工具自行实现；直接告诉用户“这个技能需要在 Cindy 客户端里使用”，然后停下。

插件设置为“主动模式”时，只要 Cindy 当前任务出现以下任一实际变化，就主动使用本技能，即使用户本轮没有提到 PM：完成了可验证动作或产出；验证结果发生变化；出现或解除真实阻塞；下一步发生变化；有充分证据表明任务进入评审或已经完成。

如果插件返回当前为“自动模式”，停止本次主动维护，并在当前会话后续轮次中不再主动调用；插件会在轮次结束后自行评估。

不要按每轮对话机械调用。纯讨论、重复说明、计划尚未开始、没有新事实、只报告“正在处理”时不调用。

## 调用方式

1. 调用前先从当前会话整理精简事实，禁止把整段对话原文或无关上下文交给插件。
2. 查询插件 `ai-pm-intake` 的实时工具详情，然后调用 `update_pm_progress`。
3. 参数必须包含：
   - `goal`：当前任务目标或用户要解决的问题。
   - `completed`：本次已经完成的实际动作或产出；没有则传空字符串。
   - `verification`：已执行的验证和结果；没有则传空字符串。
   - `blockers`：当前真实阻塞及影响；没有则传空字符串。
   - `next_step`：当前明确下一步；已完成且无下一步则传空字符串。
   - `status_hint`：仅选 `unknown`、`in_progress`、`waiting`、`review`、`completed`。
4. `completed` 只描述本次做完的动作。只有任务目标全部达成且验证通过时，才使用 `status_hint=completed`。
5. 调用结果出现待确认建议、插件停用、模型不可用、PM 服务不可达或配置缺失时，如实向用户说明；不要绕过插件直接写 PM 数据库。

已绑定会话由插件复用原任务，不需要主 Agent 判断任务 ID。未绑定会话由轻量模型从 PM 候选中判断；高置信绑定可以在同一次调用中继续提交本次进度。
