# TooManyTasks 网页入口

本目录是 React + Vite 网页入口，包含工作台、候选收件箱、全部任务、排期日历、归档、任务详情和集成设置。

集成设置中的个人信息流支持按姓名或最近私聊选择人员、按群名选择群聊；页面不展示或要求填写 `open_id/chat_id`，机器人补充入口单独折叠配置。

候选收件箱提供活动筛选与“回收站”筛选；卡片底部支持移入回收站和恢复候选。回收站只隐藏候选，不删除来源或正式任务；按钮在窄屏下允许换行并避免覆盖其他操作。

浏览器任务台直接通过当前本机任务库的 HTTP API 工作，负责确认候选、查看任务、开关自动扫描以及重启或退出后台。本机令牌与后台服务由 Cindy 插件设置管理；新候选请在 Cindy 说「扫近10分钟」。
