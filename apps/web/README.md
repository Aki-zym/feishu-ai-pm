# TooManyTasks 网页入口

本目录是 React + Vite 网页入口，包含工作台、候选收件箱、全部任务、排期日历、归档、任务详情和集成设置。

浏览器设置页承载当前 Aily 应用配置和用户 OAuth 授权。App Secret、access token 与 refresh token 由独立 TooManyTasks 的本机加密凭证库保存；页面只显示是否已保存和授权状态，不回显密钥。

候选收件箱提供活动筛选与“回收站”筛选；卡片底部支持移入回收站和恢复候选。回收站只隐藏候选，不删除来源或正式任务；按钮在窄屏下允许换行并避免覆盖其他操作。

浏览器任务台直接通过当前本机任务库的 HTTP API 工作，负责连接 Aily、确认候选、查看任务、开关自动扫描以及重启或退出后台。Cindy 插件从 TooManyTasks 私有配置目录读取自动生成的集成令牌；新候选请在 Cindy 说「扫近10分钟」。
