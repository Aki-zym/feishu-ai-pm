# 个人PM

AI 工作时代事情已经太多，信息在爆炸，分散在飞书私聊、群 @、会议和日历里，人的注意力不够用。接得住把这些散落的需求收拢成短卡片，后面新来的消息再自动往上补。

### 信息对不上号

私聊、群、会议、日历里都夹着没办完的事。过几天只记得好像有人要过一张表。谁提的、要验证什么对不上号，当时答应过什么也找不回来。

### 对方不会按你的流程来

来找数据的人很多，运营、策划、程序各有各的说话习惯。Jira 要靠对方按统一流程下单，项目里没有给数据下单的规矩，也不能要求他们先改流程再开口。

### 怎么接住

把一段时间里的线索压成短卡片，后面新来的消息再自动往上补。聊天原文不进首页，也不进任务卡。对方还是在飞书里说话。

它不帮你跑数，工作文件也动不了。对外要发出去的东西只出草稿，得你自己点头。

## 现在能做什么

- **工作台** 把一段时间里的信息压成当天要看的短清单，需要确认的、今天推进的、还在等别人的。
- **候选收件箱** 把线索压成短卡片，由你接受、暂存、忽略或移入回收站。聊天原文不进首页和任务卡，只留在本机来源记录里。
- **任务、日历和回收站** 接受后进入只有你看见的台账，可排期、归档、删除和恢复。
- **自动维护与撤销** 后续消息在高置信时可由 AI 更新任务，少翻一截旧聊天。你能看前后值和依据，一键撤销，或改成仅建议、暂停单个任务。
- **设置里选人和选群** 私聊会自动发现，默认不关注。群聊按群名选择，只处理真实 @你。
- **人工补录** 不连飞书也能把漏掉的需求加进待确认候选。日志与纠错页可回看判断、重试和补录记录。

## 怎么用

Windows 桌面和本地浏览器是长期并存的两个入口，共用同一套能力。

**本地浏览器**需要 Node.js 24。

```text
npm install
npm run dev
```

打开 `http://localhost:5173`。要看生产式预览，再跑

```text
npm run build
npm start
```

打开 `http://127.0.0.1:4310`。Windows 也可以运行 `scripts/start-local.ps1`。

**Windows 桌面** 在仓库根目录运行 `npm run desktop:dist`，再安装生成的安装包。安装后打开即可使用。

详细操作见 [用户指南](docs/user-guide.md)。

## 边界

- 只发现、记录、整理和规划任务，不执行数据分析或其他业务工作。
- 真实工作文件只读挂接，系统不会改这些文件，也不会控制其他 Agent。
- 对方继续在飞书里说话。系统不会自动回复、拉群、排期或宣布完成。
- 对外动作在当前阶段只生成本地草稿，必须由你确认后才允许另行接入发送。
- 数据、令牌和聊天原文留在本机。删除任务默认进回收站，永久清除要走设置里的隐私流程。

系统组成见 [架构边界](docs/architecture.md)，令牌、原文和删除规则见 [安全与隐私](docs/security_and_privacy.md)。
