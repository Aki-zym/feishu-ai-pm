# 视觉基准

`dashboard-concept.png` 是首个空壳的主屏视觉基准。实现重点：

- 左侧固定导航，中间使用列表而不是卡片墙。
- 候选收件与正式任务分开。
- 桌面端右侧展开详情，移动端改为完整页。
- 候选详情固定展示“时间范围、背景、希望验证、Describe、为什么被识别”。字段必须标明“来源事实 / 文档内容 / AI 整理·待确认 / 未推断出”，不能用泛话填满未知信息。
- 关联飞书文档显示类型、读取状态、版本、完整性和 stale 提示；读取失败仍保留原消息。
- 所有对外可见动作统一标记为“待我确认”。

`settings-concept-desktop.png` 和 `settings-concept-mobile.png` 是 M1 设置页重设计基准。实现重点：

- 打开设置先看到“现在是否可用”，连接总览优先于技术参数。
- 个人信息来源使用五行紧凑列表，不做卡片墙；每行显示状态、最近同步和“重新同步”。
- 飞书与判断模型是两个等高主要连接面板；OAuth 回调和 scope 直接放在飞书主卡。权限指南、机器人补充入口、本机目录和危险操作按需展开。
- 权限指南使用折叠图文步骤，分别提供“开放平台批量权限 JSON”和“推荐 OAuth scope”，支持复制与自动填入，并明确两者用途不同。
- 机器人明确标记为可选补充入口，不能与主人个人信息流同级成为主入口。
- 手机端按钮至少 44px，高级区域纵向排列；任务详情底部操作不能遮挡计划或纠错控件。

任务计划区继续沿用 `dashboard-concept.png` 的列表与右侧详情体系：计划开始/完成直接编辑，删除为红色次级动作，回收站保持表格视图而不是新增卡片墙。

现有设置概念图仍是总体层级、密度和响应式基准；OAuth 回调、scope 和权限指南的位置按用户 2026-08-11 的明确裁决调整，以当前实现和本说明为准。
